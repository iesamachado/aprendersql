Tarea: Implementación en SQL (DDL)

Módulo: Gestión de Bases de Datos (ASIR) | RA3

Objetivo de la Tarea

Traducir el diseño lógico de tablas al modelo físico escribiendo el código SQL DDL (Data Definition Language) para crear la base de datos real en el servidor.

1. Instrucciones de Código

  • Sintaxis: Debes usar las sentencias CREATE TABLE para crear todas las tablas de los 5 ejercicios anteriores.
  • Tipos de datos reales: Ya no sirven los tipos "lógicos". Tienes que decidir si usas VARCHAR(50), INT, DECIMAL(5,2), DATE, etc. Piensa en optimizar el espacio.
  • Integridad: Implementa explícitamente las PRIMARY KEY y las FOREIGN KEY con la sintaxis a nivel de tabla. No olvides añadir restricciones como NOT NULL donde sea evidente (ej. un DNI o un Nombre).
  • Orden de creación: Las tablas maestras (sin foráneas) deben crearse antes que las tablas dependientes. Si el script no ejecuta del tirón de arriba a abajo por fallos de dependencias, restará puntuación.
Atención: Queda prohibido el uso de herramientas de autogeneración de SQL (como la exportación de MySQL Workbench). El código debe ser escrito a mano para interiorizar la sintaxis.

2. Entrega

  • Debes entregar un ÚNICO archivo de texto plano con extensión .sql.
  • Usa comentarios (-- Ejercicio 1) para separar cada uno de los 5 ejercicios dentro del mismo script.
  • El nombre del archivo debe ser: Apellido1_Apellido2_Nombre_DDL.sql
