Selección de Motores: InnoDB vs MyISAM

MariaDB soporta múltiples motores de almacenamiento. Los más comunes son InnoDB y MyISAM.

InnoDB (Predeterminado)
  • Soporta transacciones (ACID).
  • Bloqueo a nivel de fila (Row-level locking).
  • Soporte para claves foráneas (Integridad referencial).
  • Recomendado para la mayoría de las aplicaciones.
MyISAM
  • No soporta transacciones.
  • Bloqueo a nivel de tabla (Table-level locking).
  • Rápido para operaciones de lectura intensiva.
  • Útil para tablas de sólo lectura o Data Warehousing.

Arranque y Parada del Servicio

Para gestionar el servicio de MariaDB en sistemas Linux basados en systemd (como Ubuntu, Debian, CentOS), se utiliza el comando systemctl.

  • Iniciar el servicio: sudo systemctl start mariadb
  • Detener el servicio: sudo systemctl stop mariadb
  • Reiniciar el servicio: sudo systemctl restart mariadb
  • Verificar el estado: sudo systemctl status mariadb
  • Habilitar inicio automático: sudo systemctl enable mariadb
Asegúrate de tener privilegios de superusuario (root o sudo) para ejecutar estos comandos.

Archivos de Log (Registro)

MariaDB genera diferentes tipos de logs que son cruciales para el monitoreo, la auditoría y la resolución de problemas.

Contiene información sobre cuándo se inició y se detuvo mysqld y también los errores críticos que ocurren mientras el servidor se está ejecutando.
Configuración típica en my.cnf: log_error = /var/log/mysql/error.log

Registra todas las consultas SQL recibidas del cliente, así como los inicios y cierres de sesión. Muy útil para depuración, pero consume mucho espacio en disco y recursos.
Configuración típica en my.cnf: general_log = 1, general_log_file = /var/log/mysql/mysql.log

Registra las consultas que tardan más tiempo en ejecutarse de lo definido en el parámetro long_query_time. Esencial para la optimización del rendimiento.
Configuración típica en my.cnf: slow_query_log = 1, slow_query_log_file = /var/log/mysql/mariadb-slow.log, long_query_time = 2.0

Parámetros de Conectividad

La configuración de red y conexión en MariaDB (generalmente en /etc/mysql/my.cnf o /etc/mysql/mariadb.conf.d/50-server.cnf) es fundamental para el rendimiento y la seguridad.

Parámetro Descripción Valor de ejemplo
bind-address Dirección IP a la que el servidor escuchará. 127.0.0.1 solo permite conexiones locales. 0.0.0.0 permite conexiones desde cualquier interfaz. bind-address = 127.0.0.1
max_connections El número máximo de conexiones simultáneas permitidas. Si se supera, los nuevos clientes recibirán el error "Too many connections". max_connections = 150
wait_timeout El número de segundos que el servidor espera actividad en una conexión no interactiva antes de cerrarla. wait_timeout = 28800 (8 horas)
interactive_timeout El número de segundos que el servidor espera actividad en una conexión interactiva antes de cerrarla. interactive_timeout = 28800
