Es muy útil en el DELETE el where con un IN y una subconsulta
Podemos localizar todos los Id's con una subconsulta y ponerla en
un IN para borrar varios registros automáticamente.
DELETE FROM menu WHERE id IN (
SELECT id FROM menu m
LEFT JOIN pedidoslinea l on l.idmenu=m.id
WHERE l.idpedido IS NULL
)
